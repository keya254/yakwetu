# Yakwetu n8n workflows · v2

Shareable copies of the workflows generated by `app/scripts/build-n8n-workflows.ts`
(`pnpm n8n:build` in `app/`). They contain **no keys**:

- The PostHog **project token** appears as `__POSTHOG_PROJECT_TOKEN__`. Replace it
  (search and replace in the JSON, or in the "Record … in PostHog" nodes after
  import) with the token from PostHog → Settings → General.
- Every other secret is an **n8n credential**, attached after import
  (RabbitMQ, Sinema recs API, Yakwetu internal API, Paystack secret, PostHog
  personal (read), Africa's Talking, Gmail, OpenAI).

The importable versions (token filled in) are written to `app/n8n/workflows/`,
which is git-ignored so they never reach GitHub.

| File | Workflow |
|---|---|
| `ykw-02-abandonment-v2.json` | YKW 02 · abandoned checkout (RabbitMQ `payment.abandoned`) |
| `ykw-03-payment-rescue-v2.json` | YKW 03 · payment failure rescue (RabbitMQ `payment.failed`) |
| `ykw-04-post-purchase-upsell-v2.json` | YKW 04 · post-purchase upsell (RabbitMQ `purchase.confirmed`) |
| `journeys.json` | Welcome and first-watch nudges (RabbitMQ `user.signed_up`) |
| `daily-digest.json` | 07:00 business report email (HTML node) |
| `ops-guard.json` | RabbitMQ health, emails on change |
| `audiences.json` | Nightly taste → PostHog person properties |
| `ask-yakwetu.json` | Staff analytics assistant (AI Agent, chat) |

The original YKW 01–04 in `../` are the storefront team's and are unchanged.
